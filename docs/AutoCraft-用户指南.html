AutoCraft 用户指南

纯客户端 Fabric Mod — 自动化原版工作台合成，专为生电红石合成站设计

一、什么是 AutoCraft？

AutoCraft 是一个运行在客户端的 Fabric Mod。它通过发包模拟玩家的容器操作，自动完成：

  1. 从输入箱子拿取原材料
  2. 走向工作台，按配方摆放物品
  3. 取出产物
  4. 存入输出箱子
  5. 循环以上步骤，直到达到目标数量

配合红石"合成站"（自动拆包/打包的红石机器），即可实现全自动批量合成。

二、硬件要求：搭建红石合成站

AutoCraft 需要一个标准的生电合成站。以下以锻造台（Smithing Table）为例。

合成站结构（俯视图）

        北 ↑

        [输入箱 A]     [输出箱]
        (铁锭)         (产物)

        [输入箱 B]     [工作台]
        (木板)         (Crafting Table)

        玩家站在此处操作

说明：输入箱可以有多个，所有输入箱视为统一的原材料池，mod 会自动扫描取用。工作台是原版合成台。输出箱存放产物。红石线路负责物料传输和拆包（此处不展开）。

合成站实物参考

   ┌──────────────┐    ┌──────────────┐
   │  📦 输入箱A  │    │  📦 输出箱   │
   │  (铁锭×128)  │    │  (锻造台×64) │
   └──────────────┘    └──────────────┘

   ┌──────────────┐    ┌──────────────┐
   │  📦 输入箱B  │    │  🔨 工作台   │
   │  (木板×256)  │    │              │
   └──────────────┘    └──────────────┘

三、完整操作流程（以锻造台为例）

配方需求

锻造台 (Smithing Table) = 4 个木板 + 2 个铁锭

工作台 3×3 摆放：
  铁锭  铁锭   (空)
  木板  木板   (空)
  木板  木板   (空)

步骤 1：保存合成表

1.1 打开工作台，按照锻造台配方摆放物品：

┌─────────────────────────────────┐
│      Crafting Table             │
│                                 │
│  ┌───┬───┬───┐   ┌──────┐      │
│  │铁锭│铁锭│   │   │      │      │
│  ├───┼───┼───┤   │ 锻造 │      │
│  │木板│木板│   │   │  台  │      │
│  ├───┼───┼───┤   │  ×1  │      │
│  │木板│木板│   │   │      │      │
│  └───┴───┴───┘   └──────┘      │
│                          [💾 +] │  ← 点击此按钮
│                                 │
│  玩家物品栏                      │
└─────────────────────────────────┘

1.2 点击右上角 💾 + 按钮，弹出命名框：

┌──────────────────────────────┐
│         Save Recipe          │
│                              │
│   ┌──────────────────────┐   │
│   │ Smithing Table       │   │  ← 默认填充产物的国际化名称
│   └──────────────────────┘   │
│                              │
│   [ Save ]     [ Cancel ]    │
│                              │
└──────────────────────────────┘
  • 输入框默认显示产物名称（中文环境显示"锻造台"，英文环境显示"Smithing Table"）
  • 按 Enter 或点 Save 保存
  • 按 Esc 取消

1.3 验证保存成功：

/autocraft recipe list

输出：

--- 已保存的合成表 ---
  锻造台 → minecraft:smithing_table x1

步骤 2：创建合成站配置

2.1 创建合成站：

/autocraft station create 主站

2.2 看向工作台，绑定：

/autocraft station set-workbench 主站

站在合成站前方，准星对准工作台方块，执行此命令。

2.3 看向输入容器，逐个添加：

/autocraft station add-input 主站       ← 第一个输入箱（对准它）
/autocraft station add-input 主站       ← 第二个输入箱（对准它）

2.4 看向输出容器：

/autocraft station set-output 主站

2.5 绑定配方：

/autocraft station bind-recipe 主站 锻造台

支持 Tab 自动补全。中文名自动加引号。

2.6 开边框高亮确认：

/autocraft station highlight 主站

效果（游戏中可见彩色边框）：

   ┌──────────────┐    ┌──────────────┐
   │ 🟢 输入箱A  │    │ 🟠 输出箱   │   ← 绿色边框=输入
   └──────────────┘    └──────────────┘      橙色边框=输出

   ┌──────────────┐    ┌──────────────┐
   │ 🟢 输入箱B  │    │ 🔵 工作台   │   ← 蓝色边框=工作台
   └──────────────┘    └──────────────┘

2.7 验证：

/autocraft station show 主站

输出：

Station: 主站
  Workbench: -129, 71, 1
  Input #0: -130, 71, 1
  Input #1: -131, 71, 1
  Output: -128, 71, 1
  Recipe: 锻造台

步骤 3：往输入箱放入材料

在输入箱 A 中放入铁锭，输入箱 B 中放入木板。mod 会自动识别。

步骤 4：启动合成

/autocraft task start 主站 64

合成 64 个锻造台。不加数字 = 无限合成（直到材料耗尽）。

启动后，覆盖层（HUD）出现：

┌──────────────────────────────────┐
│  AutoCraft [RUNNING]             │
│  Recipe: 锻造台                   │
│  Progress: 0 / 64                │
│  ░░░░░░░░░░░░░░░░░░░░░░  0%     │
│  Step: 从输入容器取材料中...      │
│  ──────────────────────────────  │
│  Input #0 (-130,71,1): OK       │
│  Input #1 (-131,71,1): OK       │
│  Output (-128,71,1): OK         │
│  ──────────────────────────────  │
│  Needed:                        │
│    iron_ingot × 128             │
│    birch_planks × 256           │
│  ──────────────────────────────  │
│  ETA: 计算中...                  │
│  [SPACE] 暂停                    │
└──────────────────────────────────┘
  • 覆盖层显示实时进度、各容器状态、所需材料
  • 按空格 暂停/恢复
  • 覆盖层出现时玩家无法操作（防误触）

步骤 5：等待完成

合成进行中，mod 自动执行以下循环：

         ┌──────────┐
         │ 分析背包  │ ← 计算还需要多少材料
         └────┬─────┘
              ↓
         ┌──────────┐
         │ 走向输入箱│ ← 逐个访问
         └────┬─────┘
              ↓
         ┌──────────┐
         │ 取原材料  │ ← shift-click 整组取
         └────┬─────┘
              ↓
         ┌──────────┐
         │ 走向工作台│
         └────┬─────┘
              ↓
         ┌──────────┐
         │ 摆放配方  │ ← 按配方位置精准放
         └────┬─────┘
              ↓
         ┌──────────┐
         │ 取产物    │ ← 循环取直到格子空
         └────┬─────┘
              ↓
         ┌──────────┐
         │ 存入输出箱│
         └────┬─────┘
              ↓
         (循环直到达到目标)

步骤 6：任务完成

任务完成后，覆盖层 5 秒淡出，聊天栏输出报告：

=================================
========== 合成报告 ==========
配方: 锻造台
产物: smithing_table x1 (per craft)
产出: 64 / 64 (100%)
耗时: 2m 15s
状态: 完成
=================================

四、命令参考

合成表管理

命令 说明
/autocraft recipe save <名称> 保存当前工作台配方
/autocraft recipe list 列出所有已保存配方
/autocraft recipe show <名称> 查看配方详情
/autocraft recipe delete <名称> 删除配方
/autocraft recipe overwrite <名称> 覆盖已有配方

合成站管理

命令 说明
/autocraft station create <名称> 创建合成站
/autocraft station set-workbench <名称> 绑定工作台（对准方块）
/autocraft station add-input <名称> 添加输入容器（对准方块，可多次）
/autocraft station remove-input <名称> <序号> 删除指定输入容器
/autocraft station set-output <名称> 绑定输出容器
/autocraft station bind-recipe <名称> <配方> 绑定合成表
/autocraft station highlight <名称> 边框高亮开关
/autocraft station list 列出所有合成站
/autocraft station show <名称> 查看合成站详情
/autocraft station delete <名称> 删除合成站

任务控制

命令 说明
/autocraft task start <站名> 启动无限合成
/autocraft task start <站名> <数量> 启动指定数量合成
/autocraft task pause 暂停（= 按空格）
/autocraft task resume 恢复
/autocraft task stop 停止
/autocraft task status 查看进度

五、特殊机制说明

批量合成策略

mod 会尽可能利用工作台格子的 64 上限：

  • 如需合成 64 个锻造台 → 工作台每格放 64 个原材料 → 循环取 64 次产物 → 一次摆满格子，高效完成
  • 尾批（如只需 12 个）→ 每格放 12 个 → 循环取 12 次

重试与停止

场景 行为
输入箱材料不足 每 2 秒检查一次，最多等待 30 秒
输出箱满了 同上，等待红石换新箱子
容器打不开 最多重试 3 次，然后跳过
所有材料耗尽 超时后停止，输出报告

输入阻塞

  • 任务运行时：所有键盘和鼠标输入被拦截（防止误操作）
  • 仅 空格键（暂停/恢复）和 Esc（菜单）可用
  • 暂停后：输入恢复正常，可手动处理问题后恢复

六、常见问题

Q: 为什么容器打不开？
A: 确保站在合成站旁边（5 格以内），方块未被遮挡。

Q: 为什么走到工作台后无法合成？
A: 检查背包中原材料是否足够。查看覆盖层中的 "Needed" 信息。

Q: 坐标重启后丢失？
A: 已修复。BlockPos 序列化为 JSON 数组 [x, y, z]，重启后正确读取。

Q: 自动补全不显示中文名？
A: 需要使用英文半角双引号包裹中文名，或直接按 Tab 自动补全（已自动加引号）。
